# Inspiration screenshots (2026-10-07)

Captured by Andre from Polymarket and Kalshi as reference for the Meridian UI revamp. Not ours;
for layout and interaction inspiration only.

- `polymarket-btc-updown-market.png` — single market page: price to beat vs current price, countdown, chart with target line, Up/Down buy panel with amount presets.
- `polymarket-crypto-list.png` — market list: cards with countdown, Up/Down rows showing payout multiple and probability.
- `kalshi-crypto-list.png` — category page with left filter rail by horizon and asset, hero market card (odds, pays out, to-beat vs now, mini chart).
- `kalshi-btc-perp-detail.png` — detail page: big live price, chart, order panel with Up/Down toggle and cost presets.

Ideas that map to Meridian: "price to beat" (strike) vs "now" (Pyth price) side by side, countdown to the 4 PM close, Yes/No as two coloured buttons with the implied probability inside, payout multiple next to each strike, ladder as rows within one ticker card.
