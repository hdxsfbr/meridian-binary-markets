# Meridian — Flow brand kit

Production-oriented developer handoff for a UI styling refresh.

**Start here:** `instructions/CODEX_INSTRUCTIONS.md`; then `BRAND.md`.

`references/original-flow-brand-board.png` is the approved visual concept. The SVG assets are editable vector reinterpretations. `references/trading-dashboard.png` is an illustrative layout, not live app UI or a verified screenshot of the current implementation.

**Use in Codex:** unzip into a project-local `design/meridian-flow/` directory, then ask Codex:

> Read `design/meridian-flow/instructions/CODEX_INSTRUCTIONS.md` and follow it to restyle the existing app. Inspect current implementation before changing anything. Preserve all trading semantics and wallet logic. Use the provided SVG assets and tokens. Run available checks and provide screenshot comparisons.

No web fonts or licensed font files are bundled; referenced UI fonts have system fallbacks.
